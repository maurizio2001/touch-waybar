# Alpine Sway

My personal lightweight tablet/desktop environment based on:

- Alpine Linux
- Sway
- Waybar
- PipeWire
- OpenRC
- fuzzel
- wvkbd

Designed to run on:

- Lenovo Duet 3
- Pocophone F1
- Future Linux devices
